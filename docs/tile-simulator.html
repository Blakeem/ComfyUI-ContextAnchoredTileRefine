    Legend

    • Tile core. The region a tile owns outright. Cores cover the image exactly, with no gaps or repeats.
    • Blend band. Feathered into the neighbor above and to the left, which was refined first.
    • Context, discarded. Sampled so the model sees past the core, then thrown away. The next tile blends that seam instead.
    • Anchor halo. Frozen pixels the tile reads but never changes. Above and to the left it holds the already-refined neighbor; to the right and below that work has not happened yet, so it is mostly raw context.
    • Sampled crop. Everything the model sees for the hovered tile.
