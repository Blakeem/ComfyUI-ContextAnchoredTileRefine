    Legend

    • Tile cores — alternating tints (checkerboard) so adjacent cores are distinguishable. Cores partition the canvas exactly; every pixel belongs to one core.
    • Context overlap — kept, feathered (green) — the part of the context_overlap band the node actually composites (paste_rect): the top and left sides, which border an already-processed neighbor in raster order. Drawn as the actual cross-dissolve: full green at the seam (the core edge), fading to transparent over the overlap (a vertical ramp on the top, a horizontal ramp on the left, and a rounded product at the top-left corner into the up-left neighbor). It ends flush at the core's right/bottom edges — the later neighbor feathers those seams. This matches the node's feather_alpha exactly.
    • Context overlap — context only, discarded (red, flat) — everything in the overlap band the node does not keep: the whole right column and bottom row, including the top-right and bottom-left overhang corners. Sampled/diffused so the model sees continuous context, then thrown away — the node pastes nothing here; the later right/lower neighbor feathers the seam instead.
    • Context anchor — frozen context, discarded — context_anchor beyond the overlap on every neighbor side: fully frozen, visible-only context, held to the ground-truth pixels every sampling step (re-anchored each step so it never drifts) so it continuously pulls the diffused overlap back toward the neighbor. Never re-diffused, never composited, always discarded from the paste.
    • Sampled crop — dashed outline on the hovered / clicked tile: the exact (symmetric) region the model sees, core + context_overlap + context_anchor on every neighbor side, at true 1:1 size.
    • Canvas edge — no overlap or anchor extends past it; cores run to the border.
    • Hover a tile for its sampled size vs the caps and which sides are kept (green) vs discarded (red); click to pin, Esc or click outside to unpin.
